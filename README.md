# People Counting System (YOLOv3-tiny)

Система подсчета входящих людей с использованием нескольких видеокамер. Проект решает задачу обнаружения и подсчета людей, пересекающих определенную зону (например, дверь), параллельно с нескольких видеопотоков.

## 🚀 Основные возможности
* **Детекция объектов:** Используется легковесная модель **YOLOv3-tiny** для высокой производительности[cite: 2].
* **Многопоточность:** Одновременная обработка нескольких видеофайлов или потоков[cite: 2].
* **Трекинг зоны:** Подсчет людей, входящих через конкретную дверь или область[cite: 2].

## 🛠 Стек технологий
* **Python 3.x**[cite: 2]
* **OpenCV**[cite: 2]
* **NumPy**[cite: 2]
